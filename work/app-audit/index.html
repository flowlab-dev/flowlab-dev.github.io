The case

Task. An Expo or React Native app works on the developer's phone, but nobody has checked whether it will pass App Store and Google Play review. A rejection means fixing it and waiting for review again, and an old SDK or a leaked key can block the release.

Solution. An audit that only reads the project files: nothing is installed or run. It compares the Expo SDK with the current one, checks app.json and the build settings, icons, the encryption flag and the privacy manifest, the iOS permission texts that often cause rejections, and looks for secrets left in the repository.

Delivered. A report in one day: what blocks the release, what should be fixed, and a step-by-step plan with hours for each fix. The sample report on this site was made on an invented project called FieldCrew, with 3 blocking issues, 10 to fix and 3 notes.

The sample project is invented. For a real app, the audit price counts toward the fixes if they are done here.
