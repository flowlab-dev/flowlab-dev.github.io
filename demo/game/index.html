How to play

  • +10 for every pastry the order still needs.
  • x2 to x4 bonus: x2 from the 6th right catch in a row, x3 from the 11th, x4 from the 16th.
  • +20 each for every item in an order when you pack it, times the bonus.
  • −10 for a pastry the order does not need. It ends the streak.
  • −20 for a burnt bun. It ends the streak too.
  • 0 for a needed pastry you let fall, but the streak ends.

    About this demo

    A promo game is a short, branded game that people open from a link and play for a minute. This one is built for an invented bakery to show how it works.

    • Opens instantly on a phone: the whole game is one small page, no app to install.
    • Mouse, keyboard and touch; three difficulty levels; pauses by itself when you switch tabs.
    • The pastries here are drawn in code for the demo; a real project uses the brand's own product art, colours and name.
    • The next steps in a real project: a shared leaderboard, a share button, a discount code at the end of the round, analytics.
