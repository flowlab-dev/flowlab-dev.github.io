РазделЧто нашлиЧто сделать
🔴СтекExpo SDK 53 отстаёт от текущего SDK 57 на 4 версии. Для магазинов сейчас нужны свежие Xcode/iOS SDK и уровни Android API — со старым SDK сборку обычно не примут.Обновить SDK по шагам (53→57), исправить несовместимости, заново проверить.
🔴Безопасность.env лежит в проекте, и .gitignore не исключает файлы .env.Убрать из репозитория, сменить ключи, добавить .env* в .gitignore.
🔴БезопасностьПохоже на секрет (Stripe live secret key) в src/billing/config.ts.Перенести на сервер или в секреты EAS и сменить: всё, что попало в приложение, может прочитать любой.
🟡НастройкиИдентификатор iOS «com.example.fieldcrew» похож на шаблонный.Выбрать окончательный идентификатор до первой загрузки в магазин — потом его не изменить.
🟡НастройкиИмя пакета Android «com.example.fieldcrew» похоже на шаблонное.Выбрать окончательный идентификатор до первой загрузки в магазин — потом его не изменить.
🟡СборкаНет eas.json: облачная сборка не настроена.Добавить профили сборки EAS (разработка / тест / магазин).
🟡App StoreЗначок 512×512, а магазину нужен 1024×1024.Выгрузить значок в 1024×1024.
🟡App StoreУ значка есть прозрачность, а значки App Store должны быть без неё.Положить значок на сплошной фон.
🟡Google PlayНет адаптивного значка Android.Добавить adaptiveIcon: передний план и цвет фона.
🟡App StoreНе указано, использует ли приложение шифрование, — App Store Connect спрашивает об этом при каждой загрузке.Задать ios.config.usesNonExemptEncryption (обычно false, если приложение шифрует только через HTTPS).
🟡App Storeexpo-camera используется, но не задан текст разрешения iOS (NSCameraUsageDescription); стандартные общие тексты — частая причина отказа App Store (правило 5.1.1).Написать для каждого разрешения конкретное объяснение, зачем оно нужно.
🟡App Storeexpo-location используется, но не задан текст разрешения iOS (NSLocationWhenInUseUsageDescription); стандартные общие тексты — частая причина отказа App Store (правило 5.1.1).Написать для каждого разрешения конкретное объяснение, зачем оно нужно.
🟡БезопасностьВ разделе «extra» конфигурации есть supabaseServiceKey — всё из extra попадает внутрь приложения.Оставить там только открытые значения.
⚪СборкаСкрипт при установке postinstall: «patch-package» (обычный инструмент).
⚪App StoreНе описан манифест приватности приложения (для своих модулей Expo добавляет его сам).Описать сбор данных и «API с обязательной причиной», если их использует приложение или подключённые библиотеки.
⚪КачествоАвтоматических тестов нет.Перед изменениями добавить тесты на ключевую логику.
