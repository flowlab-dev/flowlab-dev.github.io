Переехало вместе с выгрузкой

  • Схема, защита строк, политики30 таблиц, RLS включена у тех же 15 таблиц, что и в оригинале
  • Строкиданные демо пришли с выгрузкой, таблицы заполнила собственная функция сброса в приложении, количество совпадает с оригиналом
  • Пользователи и хеши паролейхеш совпадает с исходным
  • Права для ролей APIсохранены: с 30 октября 2026 года Supabase открывает новые таблицы для API только по явным правам (GRANT)

Что настраивается вручную в новом проекте

  • Задания по расписанию (pg_cron)не переносятся: лежат в служебной схеме cron, их создают заново
  • Собственная роль Lovableв Supabase такой роли нет, права для неё пропускаются
  • Серверный код с сервисным ключомновые ключи владелец прописывает там, где размещён сайт
  • Провайдеры входа и секретывладелец задаёт их в новом проекте
