  1. Сводит два файла по артикулуцена и остаток — всегда свежие
  2. Проверяет обязательные поляпустое поле или битая ссылка на фото — строка подсвечивается, в XML не идёт

3. XML по постоянной ссылке

Ссылку один раз вставляете в настройки автозагрузки Авито.
<Ads formatVersion="3" target="Avito.ru">
  <Ad>
    <Id>артикул</Id>
    <Address>адрес склада</Address>
    <Category>из вашего шаблона</Category>
    <ContactPhone>ваш телефон</ContactPhone>
    <Title>название</Title>
    <Description>текст + характеристики</Description>
    <Price>из файла остатков</Price>
    <Condition>новое</Condition>
    <Images>
      <Image url="https://…"/>
    </Images>
  </Ad>
  … ещё 17 объявлений
</Ads>
Постоянная ссылка: https://…/avito.xml

Дорабатывать файл данных — немного

  • уникальный номер товара (подойдёт артикул, если он не повторяется);
  • адрес, откуда продаёте, и контактный телефон;
  • фото — прямыми открытыми ссылками на картинки (с вашего сайта или хостинга картинок; помогу выложить).
Точный список скажу, когда сверю ваш файл с вашими XML-шаблонами.

Что нужно от вас

  • доступ к Google Таблице и ссылка на файл с остатками;
  • подключённая автозагрузка в вашем кабинете Авито — туда вставим ссылку;
  • после первой загрузки — отчёт автозагрузки: исправлю всё, что Авито не принял.
В ваш аккаунт Авито не входим: ссылку вставляете вы, отчёт присылаете вы.
