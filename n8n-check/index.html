Ignored model settingOpenAI chat model nodes (v1.2+) with an old modelName field run the default model instead.

No failure alertNo Error Workflow set, and the legacy execution order.

These are pattern checks on the JSON. They don't run your workflow, call your APIs or see your data, so a clean result means “none of these patterns”, not “no bugs”.
